## 可观察结果与范围

管理员可维护两个独立的 Google 账号，重新授权或删除其中一个后，另一个仍能独立刷新。在目标服务器关闭看板网页，后台仍按设定间隔查询；服务重启后能回读账号配置和各项上次成功结果。

## 验证入口

独立测试员从网页「配置管理 → 添加订阅」连接两组受控身份，通过「订阅总览」核对各自可辨认的回执，依次触发身份缺失、错配、重新授权和删除。通过配置管理修改默认 15 分钟的刷新间隔并重启服务，配合可控时钟和查询记录核对实际生效时间。

目标服务器实测使用一条实际持有的 Google 订阅。先记录账号代称、三项看板结果或状态及成功时间，关闭看板跨过一个刷新周期，再重开。逐项对照同账号、相近时间的 [Gemini Apps](https://gemini.google.com/)「设置 → 使用限额」、Antigravity 的官方 `/usage` 和 [Google One 积分活动](https://one.google.com/ai/activity)。

## 通过条件

- [x] 身份无法核对或回执属于另一账号时提示原因，错配结果未写入，旧值与原成功时间保留。重新授权一个账号后，另一个仍可刷新自己的额度。
- [x] 取消删除后该条记录及连接保留。确认删除时清除该账号的配置、凭据和缓存，后续查询跳过该条，另一账号仍能正常更新。
- [x] 验证默认 15 分钟后台刷新、修改间隔后生效。服务重启后可回读配置和上次成功结果，并按保存的间隔继续刷新。
- [ ] 实号三项分别记录官方数值或可见状态、看板结果和时间。至少一项与同账号官方结果一致，且有后台成功记录满足「关闭网页时间 < 后台成功查询时间 < 重开时间」。数值未变时，以新的成功时间及服务端查询记录核实。其余项展示实际状态或官方查看入口。（自动化契约已 PASS；实号部分待目标服务器执行）
