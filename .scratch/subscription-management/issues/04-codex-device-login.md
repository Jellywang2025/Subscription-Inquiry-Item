# 04 · 连接一个 Codex 账号并查看额度

- 产品版本 `0.2.0`
- 规格基线 [个人订阅管理系统统一 Spec](../../../spec/implement/subscription-management.md)，提交 `934c18379055de0a75c04a194f6d723381629aee`
- 验收编号 AC-02、AC-05、AC-06（单账号）、AC-09（授权页）
- 直接依赖 [01 管理员登录并进入空总览](01-admin-entry.md) 的固定 SHA 独立验收通过
- 初始状态 等待前置票验收

## 可观察结果

一个自命名 Codex 账号即可授权、查看各窗口的剩余额度比例、维护订阅信息并管理该账号。

## 验证入口

在服务器网页添加 Codex，填写自定义名称和可选付费字段。由可控设备码与额度回执驱动等待、过期、重新获取和成功。目标服务器以实际可用账号对照官方结果。

## 通过条件

- [ ] 页面显示当前账号、可复制的一次性码、有效期、官方入口及进度。设备码过期可重取，服务器确认成功后变为已连接。
- [ ] 显示官方窗口剩余比例和对应重置时间，缺少时间标为未提供。可填写并回读套餐、费用、币种、周期和续费日。
- [ ] 仅修改名称或付费信息后仍可用原连接查询。整个主流程可只用一个账号完成，无用途分类选择。
- [ ] 授权页横竖屏对照核准图。单账号总览显示一张对应卡片。
