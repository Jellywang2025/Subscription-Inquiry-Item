# 02 · 管理第一个 DeepSeek 账号并查看余额

- 产品版本 `0.2.0`
- 规格基线 [个人订阅管理系统统一 Spec](../../../spec/implement/subscription-management.md)，提交 `934c18379055de0a75c04a194f6d723381629aee`
- 验收编号 AC-02、AC-05、AC-07、AC-09（配置页、密钥表单）
- 直接依赖 [01 管理员登录并进入空总览](01-admin-entry.md) 的固定 SHA 独立验收通过
- 初始状态 等待前置票验收

## 可观察结果

从网页新增一个自命名的 DeepSeek 账号，即可查看余额、修改名称、更换密钥或删除配置。

## 验证入口

从「添加订阅」选择 DeepSeek，输入自定义名称和测试 Key，使用可控的 CNY、USD 及零额回执。在配置页依次改名、替换 Key、取消删除和确认删除，再重开页面。

## 通过条件

- [ ] 一个账号即可保存并使用，账号卡显示所填名称及成功时间。按币种分别展示总额和同币种明细，成功零额显示 0.00。
- [ ] 保存后只展示密钥末四位。仅改名保留原连接，改名同步到列表和卡片。无效新 Key 提示失败且旧连接可继续查询，有效新 Key 验证成功后生效。
- [ ] 删除确认显示平台和自定义名称。取消保留记录，确认后清除该条记录、凭据、缓存及查询对象。重开可观察到实际结果。
- [ ] 按已核准的配置页、密钥表单和总览卡片检查横竖屏，缩放时保留未提交输入。
