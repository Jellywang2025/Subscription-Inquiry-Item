## 页面与响应式规则

| 浏览器可用宽度 | 导航 | 总览与配置 |
| --- | --- | --- |
| 1251 CSS px 起 | 230 px 左栏，依次为订阅总览、配置管理 | 总览最多三列，两账号的分组可各占半行。配置列表展示名称、平台、连接状态、续费日或密钥、操作。 |
| 661–1250 CSS px | 顶部双页签，当前页签带深色下划线 | 总览两列。配置保留名称、状态、操作，平台及续费日或密钥在行内展开。 |
| 660 CSS px 及以下 | 顶部双页签，左右留白 16 px | 单列卡片与表单。账号操作另起一行。 |

调整窗口尺寸时通过样式重排同一份页面。平台筛选、搜索和表单输入保持在同一状态。

## 视觉规则

- 应用外底 `#e6ebe7`，内容底 `#fafbf9`。常规卡片白底，深卡片 `#222621`，浅灰卡片 `#eef1ec`。主字色和主按钮 `#191b1a`，边框 `#dde2de`。绿色用于连接状态和用量进度，红色用于失败提示和确认删除。
- 页面主标题 31–53 px，分组标题 21 px，账号标题 16 px。核心数值 24–42 px，窄屏为 34 px。表单与按钮 14 px，状态与明细 12–13 px。中文优先使用系统微软雅黑或苹方，数值使用 Inter 或 Segoe UI。
- 卡片间距 16 px、圆角 22 px，区块之间 28 px。表单使用 10 px 圆角输入框，主按钮 12 px 圆角、最小高 44 px。默认、悬停、键盘焦点、禁用各有可见状态。
- 主按钮承担添加、保存、打开授权页或重新获取设备码。删除入口使用低强调样式，确认框显示平台及账号名，最终确认按钮为红色。加载、失败和成功可以通过文字识别。

## 首轮构图

- **订阅总览**展示两张 Codex 账号卡、DeepSeek 与 MiMo 各一张。每张卡按账号名、连接状态、数值、明细和更新时间组织。
- **配置管理**将搜索与平台筛选放在同一行。每条账号配置有编辑和删除入口，Codex 有授权入口。刷新间隔放在列表下方。
- **Codex 授权**展示当前账号、设备码、复制、官方授权页和状态。过期后提供重新获取设备码。
- **API 密钥配置**以 DeepSeek 的替换表单出图。MiMo 使用同一结构，字段名为 MiMo SK。侧栏展示当前连接与末四位。
