# 协作试点规范 v1.0

已确认范围为统一临时目录与测试入口、自动归档 CLI 回执。两张子 Issue 以同一个 PR 交付。项目源代码行为按[产品规格](../archived/personal-quota-dashboard.md)验收。

| 验收编号 | 公开入口与结果 |
|---|---|
| GOV-01 | 测试入口在 Windows 使用独立临时目录。连续执行两轮全量检查不会在仓库根目录生成临时项或触碰个人账户缓存。显式失败返回失败码并给出保留的日志位置。受限环境可选择统一忽略目录。 |
| GOV-02 | 治理入口检查关键文档链接、规格归档口径与根目录临时项。断链或临时项导致明确的非零退出与路径诊断。CI 与本地调用同一个测试入口。 |
| GOV-03 | 测试员调用产生逐次回执，关联工单、阶段、实际 SHA、运行及会话标识、CLI 进程退出码、业务结论和耗时。解析实际可见用量，缺失明示。成功、失败或阻塞均留档，原始日志在仓库外。 |

先执行 GOV-01 与 GOV-02，再执行 GOV-03。每票记录红灯、自测、OCR 和独立验收。最终 PR 必需检查通过方可合入。
